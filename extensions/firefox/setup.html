RDM

Firefox, meet your download manager.

Connect once. Download quietly.

This Linux preview needs RDM's Rust service and Native Messaging bridge. The extension does not install native applications itself.

  1. Stop an old running service with its matching binary before upgrading. Build matching binaries from the RDM repository:
    cargo build -p rdm -p rdm-service -p rdm-gui -p rdm-native-host --release --locked
  2. Register the bridge for your user (no sudo):
    ./target/release/rdm-native-host --install
    Keep the binaries at that location. Registration refuses to replace an existing manifest.
  3. Use Check connection in the popup, or send a direct public file link. Sending a link starts the service if needed. A connection check alone does not start it.

Only when you ask

Right-click a link and choose Download with RDM, paste a URL in the popup, or use Use current tab and review before sending. A normal web page URL is not necessarily a downloadable file.

Downloads use RDM's configured folder. One managed download runs at a time; further links join the shared FIFO queue. “Queued in RDM” means it has not started yet; “Accepted” is not completion. Open the RDM GUI for queue position, removal, progress, cancellation and shutdown. The service queue and history are in memory only and are lost on service restart.

Privacy & permissions

Only a URL you explicitly choose is sent to the local Rust bridge, then to RDM. The URL can contain sensitive signatures or query tokens. RDM contacts the requested server to download it, following its existing network safety and resume-file rules.

  • Native Messaging: talk to the installed local bridge.
  • Menus: add a right-click action for links.
  • Active tab: fill a tab URL after you click the toolbar action. No all-sites access or browsing-history permission.

The manifest declares browsing-activity transmission because your selected URL leaves the extension for a local application. No analytics, telemetry, remote scripts, automatic interception, cookies, authorization headers, history scanning, or extension URL storage. Private browsing is not supported in this preview.

If something goes wrong

If a reply is lost, the download may still have started. Inspect the GUI before retrying; the extension never resends automatically. For startup failures, run rdm-service in a terminal. Check that XDG_RUNTIME_DIR is private and user-owned.

Registration is for ordinary desktop Firefox. Flatpak/Snap browser sandbox access is not configured by this preview. This is an unsigned development extension, not an AMO release.
